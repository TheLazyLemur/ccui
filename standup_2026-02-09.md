# Standup: 2026-02-09

## Summary

### Vim Navigation (Latest)
Added keyboard-driven navigation for power users:
- `h/l` - switch between left/right panels
- `j/k` - scroll chat up/down
- `gg/G` - jump to top/bottom of chat
- `i` or `/` - focus input field
- Disabled in terminal panel to avoid conflicts
- Full test coverage (123 lines of tests)

### Scheduled Automations System
Built a complete automation framework for recurring agent tasks:
- **Engine**: Context-aware execution with cancellation support
- **Scheduler**: Cron-based scheduling with persistent store
- **Skills**: Reusable automation templates (dependency check, security scan, stale branch cleanup)
- **Worktree support**: Run automations in isolated git worktrees
- **Triage panel**: UI for reviewing automation results and findings
- **Permission levels**: Read-only, workspace-write, or full access controls

### Unified Backend Architecture
Refactored to support multiple AI backends through a common interface:
- Extracted `AgentBackend` interface with `NewSession()` method
- Both ACP and Anthropic backends now implement the same interface
- Session options support review-mode features (auto-permission, tool event suppression)

### Anthropic Backend (Direct API)
Completed full implementation for direct Anthropic API usage:
- SSE streaming parser with Kimi compatibility (`event:X` format)
- Tool execution loop with permission checking
- Event emission: `message_chunk`, `thought_chunk`, `tool_state`, `file_changes`, `prompt_complete`
- Configurable base URL for custom endpoints (via `ANTHROPIC_BASE_URL`)
- Fixed permission response routing to correctly map toolId+optionId

### Tool Infrastructure
- **Edit tool**: String replacement with validation (unique match checking, `replace_all` option)
- **Glob tool**: Pattern matching for file operations
- **Grep tool**: Regex search across codebase
- **Bash tool**: Command execution
- **Read/Write tools**: File I/O operations
- Anthropic tool schemas for all tools
